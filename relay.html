    What did the language do?
    The contract below declares the request shape and a record-forward activity. A separate, manually triggered CI can check it and export its graph with a pinned Gooo compiler. That does not validate this game's JavaScript transition rules.
    package relaygame
namespace relaygame

entity TurnRequest id "gooo://relay-game/request" fields {
    field RunID id "gooo://relay-game/request/run-id" type string required one
    field Turn id "gooo://relay-game/request/turn" type string required one
    field Action id "gooo://relay-game/request/action" type string required one
    field Direction id "gooo://relay-game/request/direction" type string required one
}
activity ForwardTurn(TurnRequest) -> TurnRequest computes "record.forward:v1"
