START SMALL

One declaration.
A traceable meaning.

Gooo starts with things, activities, and their relationships. You do not need to start by building an autonomous agent.

The language is experimental. Use the repository instructions for the exact checkout or release you choose. Development examples may require features absent from an older release.

A real compiler fixture

This is the source form of a registration fixture exercised by the compiler tests, not a browser-hosted compiler.

package registrationfixture
namespace registrationfixture

entity Observation id "gooo://registration-fixture/observation" fields {
    field State id "gooo://registration-fixture/state" type string required one
}
activity Capture(Observation) -> Observation computes "record.forward:v1"

Observation has an explicitly identified field. Capture declares an input, output, and bounded computation. The compiler checks these declarations rather than inferring them from a description.

Choose your next step

  • Read the repository setup instructions for the version you want to use.
  • Explore compiler examples before adding a new domain.
  • Choose an experimental release; a merged PR is not a published release.
  • Understand the semantic model and generation boundary.

Ask a precise question

What is the input? Which operation may act on it? What output should exist? Which observation would support or contradict the claim? A small answer that can be checked is more useful than an impressive completeness score.
